# MG Händlermanager – Updates

Öffentliche Versionsdatei für den **MG Händlermanager** von MG Commerce.
Das Programm fragt einmal am Tag nur `mg_haendlermanager_version.json` ab – es werden keine Daten übertragen.

- Neue Version: oben in `verlauf` eintragen, `version`, `datum` und `download` aktualisieren.
- Setups **nicht** ins Repository legen, sondern als **GitHub Release** (Tag `vX.Y.Z`) hochladen und
  den Release-Link als `download` eintragen. So bleibt das Repository klein.
